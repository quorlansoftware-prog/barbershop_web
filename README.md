# BarberShop Web 💈

Sitio web moderno y elegante para la barbería de alta gama **BARBER & CO**, desarrollado para la organización **Quarlon Software**.

## 🌟 Características
- **Diseño Luxury & Dark Mode**: Estética moderna en tonos oscuros y dorados con efectos de glassmorphism.
- **Reserva de Citas Online**: Modal dinámico para selección de servicio, fecha y hora.
- **Menú de Servicios**: Catálogo detallado de cortes, arreglos de barba y paquetes gentleman.
- **Reseñas & Opiniones**: Valoraciones de clientes satisfechos.
- **Diseño Totalmente Adaptativo (Responsive)**: Optimizado para dispositivos móviles, tablets y escritorio.

## 🚀 Tecnologías
- HTML5 Semántico
- CSS3 (Variables CSS, Flexbox & Grid Layout)
- JavaScript ES6+
- Google Fonts & FontAwesome Icons
