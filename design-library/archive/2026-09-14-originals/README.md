# Archivo de estilos anteriores

Se conservan aquí las referencias de las tres demos previas: Bourbon, Neon y Minimal. Sus archivos originales siguen en `public/assets/` para que el historial y las direcciones existentes sean recuperables. No se han eliminado ni sobrescrito; las nuevas rutas usan nombres explícitos (`hero_bourbon`, `hero_pure`, `hero_forma`).
