# Shared foundations

Los presets comparten:

- clases públicas `awc-*` de `@quorlansoftware/astro-web-components`;
- navegación fija, modal de reserva demostrativo y estados accesibles;
- escala de espacios de 8 px y breakpoints 768 / 992 px;
- movimiento suave con fallback sin JavaScript y `prefers-reduced-motion`.

Cada preset puede cambiar color, tipografía, radio, sombra, recorte de imagen y composición mediante sus tokens.
