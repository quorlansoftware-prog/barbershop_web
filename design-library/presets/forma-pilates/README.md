# Forma · Pilates boutique

Ficha de diseño para un estudio de movimiento que combina precisión deportiva con una presentación editorial.

- **Paleta:** blanco tiza `#f4f3ee`, azul cobalto `#1746d1`, lima `#d8f04a`, tinta `#101622`.
- **Tipografía:** Space Grotesk para titulares geométricos y DM Sans para indicaciones y lectura larga.
- **Composición:** hero con sujeto desplazado, bloques cobalto, explicación del método y modalidades de iniciación, reformer y sesión individual.
- **Movimiento:** desplazamientos breves y cambios de escala muy contenidos; se desactivan con `prefers-reduced-motion`.
- **Uso recomendado:** estudios de pilates, yoga y entrenamiento personal que venden clases, bonos o sesiones de prueba.

Los tokens y la implementación portable viven en `tokens.css` y `theme.css`. Los prompts y la procedencia de imágenes están en `prompts.md`.
